## What CanvasDraft Studio Is

CanvasDraft Studio lets you draw right inside a web browser. Everything runs on vanilla JavaScript and a purpose-built HTML5 canvas renderer, so you get a compact editing surface for building and adjusting visual scenes without installing a desktop program.

Artwork is held in a scene graph, which keeps drawn content organized as discrete elements, and an undo/redo history stack lets you step back and forth while revising. It fits two audiences: anyone who wants a small drawing tool that opens in a tab, and developers curious about how a canvas app can be put together with plain web technology.
